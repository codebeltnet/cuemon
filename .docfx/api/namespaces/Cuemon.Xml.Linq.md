Parse and validate XML strings using LINQ to XML extension methods. Use this namespace when you need to validate XML strings or safely attempt XML parsing. Start with `TryParseXElement` on `IDecorator<String>` for safe element-level XML parsing, or `IsXmlString` to check whether a string is valid XML.
