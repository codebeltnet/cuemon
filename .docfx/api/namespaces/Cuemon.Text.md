Parse strings into strongly-typed values, control GUID formatting, perform suffix-based string operations, and detect text encodings when the built-in `System.Text` types are not enough. Use this namespace when you need advanced text processing like string parsing, GUID formatting, or encoding detection. Start with `Parser<T>` for parsing strings into typed values, or `GuidStringOptions` for GUID format control.
