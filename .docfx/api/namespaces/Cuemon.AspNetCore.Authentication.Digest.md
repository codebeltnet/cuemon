Implement [Digest Access Authentication (RFC 7616)](https://en.wikipedia.org/wiki/Digest_access_authentication) in your ASP.NET Core application with middleware, handler, and nonce tracking types. Use this namespace when you need challenge-response authentication that avoids sending passwords in clear text. Start with `DigestAuthenticationHandler` for authentication or `DigestAuthenticationMiddleware` for pipeline integration.
