The `Cuemon.Collections` namespace provides specialized collection types — including sorted, bounded, and pageable collections — that extend beyond the standard .NET collection types for more specific data storage needs.

Use this namespace when you need collection semantics that go beyond `List<T>` or `Dictionary<TKey,TValue>`, such as bounded queues or sorted sets. Start here for foundational collection types.
