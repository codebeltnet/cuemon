The `Cuemon.Runtime.Serialization.Converters` namespace provides converter types that serialize and deserialize objects to and from a generic node representation, inspired by JSON.Net's converter model. Use `StringConverter` or `DateTimeConverter` to control how specific types are represented in the node-based serialization pipeline.
